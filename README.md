# idp
LayoutLMv3 classifier for 4 classes.

1. Training, validation and quantization are done and explained in the **train** folder.
2. The inference pipeline with Architectural diagram (data flow from image path into final prediction with intermideate output), the design for short and long context explained in **train**. I have built based on the podder-task-foundation which worked for me before to inference pipeline and easy to understand how does the inference works and how it can be controlled, debug intermediate steps.
